SAKURA BLOOM DYNAMICS - TEMPORAL & PHASE-SPACE PLOTS
=====================================================
Generated by generate_sakura_plots.py from:
  - sakura_first_bloom_dates.csv  (x1 = first bloom day-of-year)
  - sakura_full_bloom_dates.csv   (x2 = full  bloom day-of-year)
for all 102 JMA/Kaggle observation stations in Japan, 1953-2025.

FOLDER STRUCTURE
----------------
temporal_plots/{idx:03d}_{station}_temporal.png
    Top panel:    x1 vs t   (first bloom day vs year)
    Bottom panel: x2 vs t   (full  bloom day vs year)
    Each panel includes a least-squares trend line (days/decade) and the
    station's official 1991-2020 climatological average as a reference line.

phase_space_plots/{idx:03d}_{station}_phase_space.png
    Top panel:    dx1/dt vs x1
    Bottom panel: dx2/dt vs x2
    Points are colored by year (colorbar) and connected in time order (thin
    gray line) so you can see how the trajectory has drifted/rotated in
    phase space over the 73-year record, not just its instantaneous shape.

plot_manifest.csv
    One row per station: data coverage (n points, year range), fitted
    trend (days/decade) for x1 and x2, species notes, and the exact
    filenames of that station's two PNGs. Use this to quickly find, e.g.,
    stations with sparse data or the strongest/weakest trends.

METHODOLOGY NOTES
------------------
1. Day-of-year (DOY) is LEAP-YEAR NORMALIZED: every calendar date is mapped
   onto a fixed non-leap reference year (2001) before computing its numeric
   x-value, so "April 10" always equals the same x regardless of whether
   that particular year was a leap year. Without this, dx/dt would pick up
   a spurious +/-1 day artifact purely from the calendar structure.

2. dx/dt is computed with numpy.gradient(x, t), using central differences on
   the ACTUAL year values. This correctly handles stations with missing
   years (gaps in observation) rather than assuming uniform 1-year spacing.

3. Stations with fewer than 2 valid data points (e.g. Yakushima, n=1) cannot
   support a derivative; their phase-space panel shows an explicit
   "insufficient data" message instead of an empty/misleading plot.

KYOTO - IMPORTANT CAVEAT
-------------------------
Kyoto is included as station #66, generated from the Kaggle/JMA source only
(1953-2025) and labeled "Kyoto [Kaggle/JMA source, 1953-2025]" in both its
title and filename (066_Kyoto_KaggleJMA_*.png).

Per the assignment notes, Kyoto ALSO has a much longer, independently
compiled historical record (Yasuyuki Aono's phenological reconstruction,
~812 AD onward, archived at NOAA paleoclimatology). That file is NOT among
the current project's inputs, so it is NOT included in this batch. See
kyoto_aono_template.py (in the scripts folder) for a ready-to-adapt script
that will produce a separately-labeled "Kyoto [Aono historical source]"
temporal + phase-space pair, using the exact same conventions, once that
file is obtained. The two Kyoto sources should be compared side-by-side,
never merged into a single series.

REGENERATING
------------
    python generate_sakura_plots.py \
        --first sakura_first_bloom_dates.csv \
        --full  sakura_full_bloom_dates.csv \
        --outdir sakura_plots
